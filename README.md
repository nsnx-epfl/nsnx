# NSNX Website 🧠

This is the official GitHub repository for hosting the website of **NSNX** (the EPFL Neuro-X Students Association). 🥳

The website is built using static HTML, CSS, and JavaScript, and is automatically deployed via GitHub Pages.

---

#### 🛠 For Maintainers

If you are taking over the maintenance of this website, please read the **[`transition.md`](transition.md)** file. It contains a complete, easy-to-follow guide on the website's architecture, file structure, and instructions on how to update content.
